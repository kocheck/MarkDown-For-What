# MarkDown For What — UI Redesign Design

**Date:** 2026-03-15
**Status:** Approved
**Branch:** kyle/redesign
**Figma file:** `y9WmO9vFpMCnMKORSjvvyQ`

---

## Context

The plugin UI is being fully redesigned to match a new Figma spec. The new design replaces the current light theme (`#EFF4F2` background) with a full dark aesthetic, introduces three custom fonts, and updates all component visuals. The existing component architecture (`mfw-*` web components, `tokens.ts` → CSS custom properties, panel HTML partials) is retained — only the visual layer changes.

The redesign covers all 4 tabs (Import, History, Settings, Export) plus a new error state for the Import panel.

---

## Approach: Foundation First (Layer 1 → 2 → 3)

```
Layer 1: Design System Foundation
  tokens.ts       ← clean break, new Figma token names + values
  src/fonts/      ← bundled font files (Space Grotesk, Geist Mono, Geist Pixel)
  styles.css      ← dark theme rewrite, @font-face declarations

Layer 2: Component Visual Updates (mfw-*)
  Structural changes to tab-bar, button, drop-zone, settings-row, section-header
  Token-only updates to remaining components

Layer 3: Panel Layout Updates
  panel-import, panel-history, panel-settings, panel-export
```

## Layer 1: Design System Foundation

### `tokens.ts` — Clean Break

All current token names are replaced with Figma-aligned names. The build pipeline (`npm run build:tokens` → `tokens.css`) is unchanged.

**Color tokens:**

```typescript
Color = {
  // Backgrounds
  gray1:  '#161616',  // main bg
  gray2:  '#1c1c1c',  // elevated surface (tab bar, file rows)
  gray3:  '#232323',  // input bg, drop bg, subtle surface
  gray6:  '#343434',  // border muted, dividers
  gray8:  '#505050',  // border strong, version text
  gray11: '#a0a0a0',  // text muted, meta, labels
  gray12: '#ededed',  // text default

  // Mint (accent)
  mint8:  '#006d5b',  // accent border + inset shadow
  mint9:  '#70e1c8',  // accent glow
  mint10: '#25d0ab',  // accent fill (primary button bg)
  mint11: '#25d0ab',  // accent text

  // Red (error / destructive)
  red8:   '#aa2429',  // error border
  red10:  '#f2555a',  // error fill
  red11:  '#ff6369',  // error text

  // Orange (warning / in-progress)
  orange11: '#ff8b3e',
}
```

**Font tokens:**


**Unchanged tokens:** `Spacing` (xs–xl), `Radius` (sm–lg), `Transition` (fast, spinner).

### Font Loading

Font files are bundled in `src/fonts/`. Webpack already handles assets referenced from CSS — no build config changes needed.

`styles.css` gets `@font-face` declarations at the top:
- `Space Grotesk` — Regular (400), Bold (700)
- `Geist Mono` — Medium (500), SemiBold (600)
- `Geist Pixel` — Square style (400)

### `styles.css` — Dark Theme Rewrite

- `body` background → `--color-gray1`
- All component-level color references updated to new custom property names (generated by `tokens.css`)
- Tab bar active state: `3px` mint bottom border + radial gradient glow background + `text-shadow` mint glow on label text
- Global font stack updated to Space Grotesk as default sans-serif

## Layer 2: Component Visual Updates

### Structural Changes (new markup or new variants)

**`mfw-tab-bar`**
- Active tab: `3px` solid mint bottom border, radial gradient background (mint → transparent from bottom), `text-shadow` glow on label
- Inactive tabs: `gray11` text, subtle gray radial gradient background
- Tab height: `42px`

**`mfw-button`**
- Add `variant` attribute: `"primary"` | `"destructive"` | `"ghost"`
- `primary`: mint fill (`mint10`), mint glow box-shadow, inset mint shadow (`mint8`), `gray1` text
- `destructive`: `gray2` bg, red text (`red11`), red inset shadow, red border (`rgba(41,20,21,0.32)`)
- `ghost`: `gray2` bg, `gray11` text, `gray3` border — used for secondary actions (Preview)
- Min size: `32px` height, `96px` min-width, `8px` icon + label gap

**`mfw-drop-zone`**
- Icon container: `48x48px`, mint fill (`mint10`), mint border (`mint8`), mint glow box-shadow, inset mint shadow
- Drop area background: radial vignette gradient (`#232323` center → darker edges)
- Label: Space Grotesk Bold 14px (`gray12`)
- Sub-label: Geist Pixel 10px (`gray11`)
- Border: `1px solid gray6`, `4px` radius

**`mfw-settings-row`**
- Label: Geist Mono Medium 12px (`gray12`)
- Input field: `28px` height, `64px` width, right-aligned value, Geist Mono Medium 12px
- Unit suffix (`px`): Geist Pixel 11px (`gray11`)
- Select field: `130px` width, chevron-down icon right-aligned

**`mfw-section-header`** (new component or updated pattern)
- `//` prefix: Inter Bold, `gray6` color
- Label: Geist Pixel, uppercase, `0.66px` letter-spacing, `gray11`
- Used everywhere a section is labeled

## Layer 3: Panel Layout Updates

### `panel-import.html`

**Normal state:**
- Section header: `// MARKDOWN_FOR_WHAT`
- Drop zone component (full width, `160px` height)
- Divider row: line — `or paste Markdown text` — line (Geist Pixel 9px `gray11`)
- Paste area: `64px` height, `gray3` bg, `gray6` border, `12px` padding
- Section header: `// SELECTED`
- File list component

**Error state** (triggered when unsupported file types are dropped):
- Section header: `// IMPORT_ERROR`
- Centered layout with `48px` red icon container (alert icon), error title (Space Grotesk Bold 14px), two-line message (Geist Pixel 10px)
- File list showing the invalid files (damaged file icon, filename, `unsupported format — .ext` meta)
- Bottom bar: `INVALID_FILE` status dot + text, destructive "Try Again" button

### `panel-history.html`

- Section header: `// RECENT IMPORTS`
- File list rows: filename (Space Grotesk Bold 13px) + `{date} · {n} blocks imported` meta (Geist Pixel 9px)
- Bottom bar: `{n} FILEs` count text left, destructive "Clear" button right

### `panel-settings.html`

Four sections, each with a section header + settings card (`gray2` bg, `gray3` border, `6px` radius, `12px` padding, `12px` gap between rows):

1. `// THEME` — 3-segment selector: Light / Dark / Docs. Active segment: mint fill, mint border, mint glow. Inactive: plain text `gray11`.
2. `// SPACING` — `block_spacing` (number input + `px`), `list_spacing` (number input + `px`)
3. `// FRAME` — `padding` (number input + `px`), `width` (select dropdown)
4. `// COLORS` — `frame_fill` (hex input + color swatch), `code_background` (hex input + swatch)

Bottom bar: `MDW v4.1` version text left (`gray8` Geist Pixel), destructive "Reset Defaults" button right.

### `panel-export.html`

- File info block: filename (Space Grotesk Bold 16px `gray12`) + block summary (Geist Pixel 10px `gray11`)
- Status row: `6px` mint dot + `READY_TO_EXPORT` text (Geist Mono SemiBold 10px `mint11`)
- Export log card (`gray2` bg, `gray3` border, `4px` radius):
  - Section header: `// EXPORT_LOG`
  - Log entries: check icon + Geist Mono Medium 10px `gray11` text
  - In-progress entry: loader icon + `orange11` text
- Bottom bar: ghost "Preview" button left, primary "Export.md" button right

## What Is Not Changing

- Build pipeline (`tokens.ts` → `build:tokens` → `tokens.css`, webpack, `build:html`)
- Web component architecture (no shadow DOM, safe DOM methods, reconnect guard)
- Component registration pattern (`mfw-index.ts`)
- Panel/shell assembly system
- All plugin logic (`code.ts`, `parser.ts`, `renderer.ts`, etc.)
- Test setup and existing component tests (tests updated for new token names)
