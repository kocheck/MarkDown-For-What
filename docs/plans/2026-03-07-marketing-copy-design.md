## Goal

Write marketing copy for the Figma Community listing and update the project README. Copy should be platform-agnostic (Sketch support planned).

## Audience

Designers, developers, and product managers — the full product team. People who write or receive Markdown and work in design tools.

## Tone

Playful and irreverent. Leans into the "MarkDown For What" name. Punchy, a little cheeky — a tool for people who hate boring workflows.

## Key Differentiators (all equal weight)

1. **Batch drag-and-drop** — multiple files at once, each gets its own frame
2. **Auto-styling** — generates real Figma text styles (`Markdown/H1`, `Markdown/Body`, etc.) editable globally
3. **Smart re-import / sync** — drop the same file again, it finds and replaces the existing frame in place

### Figma Community Listing

**Title:** MarkDown For What

**Tagline:**
> You wrote the doc. Stop rebuilding it in Figma.

**Description:**
> MarkDown For What turns your Markdown files into structured design frames — automatically. Drop in a file (or a dozen), and it builds out headings, body text, code blocks, tables, and images as proper Auto Layout frames with real text styles. Update the source file later? Drop it again. It finds the frame and replaces it in place.
>
> No copy-paste. No style hunting. No duplicates.

**How it works:**
1. Drop your `.md` files into the plugin
2. Frames appear — named, styled, and laid out
3. Changed something? Drop it again. It replaces in place, no duplicates.

**Features:**
- Drag in one file or twenty — each gets its own frame
- Headings, lists, code blocks, tables, and images all render properly
- Generates real text styles (`Markdown/H1`, `Markdown/Body`, etc.) you can edit globally
- Smart re-import matches files to existing frames by name
- Strips YAML front matter automatically
- Runs entirely locally — nothing leaves your machine
